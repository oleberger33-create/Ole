# Flausenfabrik

**Unsinn am Fließband.** Marke für einen deutschsprachigen YouTube-Kanal mit KI-animierten Unterhaltungsvideos.

Fussel hat die Ideen. Die Maschine KURT setzt sie um, leider wörtlich. Und Taube Brösel will eigentlich nur Feierabend.

## Inhalt

| Datei | Wofür |
| --- | --- |
| `markenhandbuch.html` | Das komplette Markenhandbuch: Markenkern, Logo, Farben, Schrift, Figuren, Look, Tonalität, Formate, Thumbnails, Kanal-Kit, Startplan |
| `assets/logo/` | Logo quer, gestapelt, Wortmarke (jeweils dunkel und `-hell`), Bildmarke Fussel. Alle als SVG, Schrift in Pfade umgewandelt |
| `assets/figuren/` | Modellblätter von Fussel, KURT und Brösel als SVG |
| `assets/youtube/` | Fertige Upload-Dateien: Profilbild 800×800, Banner 2560×1440, Wasserzeichen 150×150, drei Thumbnail-Beispiele 1280×720 |
